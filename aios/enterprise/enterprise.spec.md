# Enterprise Features

Enterprise-grade tools for observability, simulation, planning, and governance.
All features are optional — loaded on demand.

| Decision Journal | ADR search and export | Decision Brain |
| Project Health | Real-time quality dashboard | All engines |
| Learning Engine | Pattern detection from history | History Brain |
| Knowledge Base | Searchable conventions and lessons | Knowledge Brain |
| Roadmap Generator | Feature delivery timeline | Planner, Feature Brain |
