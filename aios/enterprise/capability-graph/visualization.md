# Capability Graph — Visualization Standards

## Node Styling
```
Capability nodes:  rounded rectangle, color by group
Module nodes:      rectangle, color by layer
```

## Color Scheme
| Group | Color | Hex |
|-------|-------|-----|
| Routing | Green | #4CAF50 |
| Planning | Blue | #2196F3 |
| Intelligence | Purple | #9C27B0 |
| Implementation | Orange | #FF9800 |
| Validation | Red | #F44336 |
| Ecosystem | Grey | #607D8B |
| Knowledge | Teal | #009688 |

## Layout Direction
- Left to right (default)
- Top to bottom (when > 10 nodes per level)
- Hierarchical: modules on top, capabilities below
